# DealGo Admin Web

Kênh vận hành nội bộ (Next.js) — kiểm duyệt, giám sát đơn/chuyến, xử lý sự cố, cấu hình và báo cáo.

Không phải role thứ tư trong app Flutter.

## Chạy

```bash
npm install
npm run dev
```

Mở [http://localhost:3000](http://localhost:3000).

## Stack scaffold

- Next.js 16, React 19, Tailwind CSS v4
- API contract lấy từ `backend/` / `docs/` đã xác nhận — không bịa endpoint
