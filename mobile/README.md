# DealGo Mobile

Ứng dụng Flutter đa vai trò (**Customer / Merchant / Driver**) cho Ride và Food.

## Chạy

```bash
flutter pub get
flutter run
```

## Ghi chú

- Package ID hiện tại: `com.trancongtien.dealgo` (Android / iOS).
- State management, DI, router và HTTP client **chưa** khóa bằng ADR — xem `docs/` và `AGENTS.md`.
- Mockup và asset UI nằm ở `../design/`.
