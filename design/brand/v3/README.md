# DealGo logo v3

Bộ logo được dựng lại theo mẫu tham chiếu: chữ D chuyển động màu tím và tuyến kết nối ba điểm màu xanh.

- `mark.svg`: biểu tượng nền trong suốt.
- `logo-primary.svg`: lockup ngang dùng trên nền sáng.
- `logo-reversed.svg`: lockup ngang dùng trên nền tối.
- `app-icon.svg`: biểu tượng ứng dụng có nền tím bo góc.
- `png/`: bản PNG alpha thật ở 2K và 4K.

Màu chính: purple `#6D28D9`, purple light `#7C3AED`, green `#10B956`, green light `#20D86B`.

SVG là file master nên có thể phóng lớn không giới hạn. PNG 2K/4K được xuất trực tiếp từ SVG, không nội suy từ ảnh raster tham chiếu.
