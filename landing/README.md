# DealGo Landing Page

Trang landing page độc lập, tách biệt hoàn toàn với Admin Web (`website/`).

## Stack

- **Next.js** 16.4
- **React** 19.3
- **Tailwind CSS** v4
- **TypeScript** 5

## Chạy dev

```bash
npm install
npm run dev   # http://localhost:3002
```

> Port mặc định: **3002** (website dùng 3000, backend dùng 3001)
